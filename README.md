# Apartment Plan

## 한국어

**당신만의 아파트 단지를 만들어 보세요.**

Apartment Plan은 구역과 입구를 지정하고, 선택한 아파트 에셋으로 단지를 계획하고 배치하는 Cities: Skylines II 모드입니다. 건물·내부 도로·주차 공간·보행로·조경을 미리보기로 확인한 뒤 직접 건설을 확정할 수 있습니다.

주차가 부족하면 유휴부지 주차 보충을 켤 수 있습니다. 완성된 경계의 변을 잡아 꼭짓점을 추가할 수 있으며, 저장하지 않고 닫을 때 확인 안내가 표시됩니다.

### 시작하기

1. Apartment Plan과 필수 에셋 팩 [AP Invisible Road Pack](https://mods.paradoxplaza.com/mods/165049/Windows), [CS KR Parking Pack](https://mods.paradoxplaza.com/mods/149013/Windows)을 같은 플레이셋에서 활성화합니다. CS KR Parking Pack은 주차 데칼 표시에 필요합니다.
2. 화면 우상단 Apartment Plan 메뉴에서 구역과 입구를 지정합니다.
3. 사용할 건물 에셋과 배치 조건을 선택하고 계획도를 확인합니다.
4. 실제 배치 미리보기에서 게임의 건설 검사 결과를 확인한 뒤 적용합니다.

현재는 **판상형 아파트** 제작을 지원합니다. 탑상형과 빌라는 준비 중입니다. 설치된 단지는 단지 편집에서 변경 계획을 만들고, 확인 후 기존 단지 시설을 삭제하고 수정 계획으로 다시 배치할 수 있습니다.

### 참고 사항

- 개발 중인 0.1.70 버전입니다. 중요한 도시는 별도 저장본으로 보관해 주세요.
- 기존 도로를 손상시킬 수 있는 변경이나 게임이 거부한 배치는 적용되지 않을 수 있습니다.
- 단지 수정 배치는 기존 시설을 삭제합니다. 삭제 후 배치를 취소해도 시설이 자동 복원되지는 않습니다.
- 단지에 사용한 건물·도로 에셋은 세이브의 의존성이 될 수 있습니다. 구독 해제 후 로드를 보장하지 않습니다.
- 소개 이미지는 사용 예시이며 일부 UI는 현재 버전과 다를 수 있습니다.

### 진단 공유

오류 옆 공유 버튼을 누르고 안내에 동의한 경우에만 제한된 진단 요약을 제작자의 사이트 DB로 전송합니다. 자동 전송은 없습니다. 버전·오류 코드·편집 및 계산 상태·객체 수·검증 수치가 포함되며, 전체 로그·계정 이름·파일 경로·에셋 이름·좌표·세이브 파일은 전송하지 않습니다. 통신은 HTTPS를 사용합니다. 서버는 IP를 수신하지만 요청 제한에는 일별 HMAC 식별자를 사용하며 진단 DB에 원본 IP를 저장하지 않습니다. 호스팅 접속 로그에는 IP가 별도로 남을 수 있습니다.

## English

**Make your own apartment complex.**

Apartment Plan lets you define an area and its entrances, choose apartment assets, and plan a residential compound in Cities: Skylines II. Preview buildings, internal roads, parking, pedestrian paths and landscaping before confirming construction.

Enable open-space parking infill when parking is insufficient. Insert vertices by picking a completed boundary edge, and receive a confirmation before discarding unsaved edits.

### Getting started

1. Enable Apartment Plan and both required asset packs, [AP Invisible Road Pack](https://mods.paradoxplaza.com/mods/165049/Windows) and [CS KR Parking Pack](https://mods.paradoxplaza.com/mods/149013/Windows), in the same playset. CS KR Parking Pack is required for parking decals to appear.
2. Open Apartment Plan from the top-right menu and define the boundary and entrances.
3. Choose building assets and layout settings, then review the plan.
4. Open the construction preview, check the game's validation results, and apply it.

**Slab apartment layouts** are currently available. Tower and villa modes are in preparation. For an existing compound, edit its plan, confirm removal of its existing facilities, then preview and apply the revised layout.

### Notes

- Version 0.1.70 is in development. Keep a separate save of important cities.
- Construction may be blocked when it would damage existing roads or fails the game's validation.
- Compound replacement removes existing facilities. Cancelling placement afterwards does not automatically restore them.
- Placed building and road assets may remain save dependencies. Loading after unsubscribing is not guaranteed.
- Promotional images show usage examples; some UI details may differ from the current version.

### Diagnostic sharing

A limited diagnostic summary is sent to the developer's site database only after you press Share and consent to the notice. There are no automatic submissions. Reports include versions, error codes, editing/calculation state, object counts and validation metrics. They exclude full logs, account names, file paths, asset names, coordinates and save files. Transmission uses HTTPS. The server receives your IP but uses a daily HMAC identifier for rate limiting and does not store the raw IP in the diagnostic database. Hosting access logs may separately retain it.
